# 检测场景

12个苹果样本分4批，每个样本初检P01为<0.01mg/kg，采样日标准限量0.005，因此不确定。次日同样本同方法复检0.004且LOD0.001，判为PASS并替代原报告。每样本P02为30ug/kg，超过0.02mg/kg，仍FAIL。最终24项目，12PASS、12FAIL，四批均FAIL。脏批额外含缺LOD、同版冲突、错列、空行与重复表头。

## 限量目录重叠裁决

`limits_overlap.csv` 中苹果/P01的V2（至2027-01-01）与V3（自2026-12-31，限量收紧0.005→0.003）生效期重叠2026-12-31一天。`overlap_day.csv` 含该日采样的在途批次C101（P01定量0.004）与重叠日后批次C102。切换目录时登记裁决 `苹果|P01→APL-P01-V2`：C101按旧版0.005判PASS并标记裁决，C102按新版0.003判FAIL。未登记裁决则C101的P01行按VERSION隔离；沿用旧目录则C102无版可用同样隔离。
